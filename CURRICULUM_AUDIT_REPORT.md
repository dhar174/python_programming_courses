The Advanced curriculum is positioned to directly address **PCAP (Certified Associate in Python Programming)** certification, with intentional design 'trajectory' markers pulling learners towards the more rigorous **PCPP1** standards. Based on the audit metrics:

This shows an exceptionally high degree of alignment between the raw instructional materials and the target runbook/syllabus goals.

  - **Hour 3:** Day 1, Hour 3: Properties, Invariants, and Custom Exceptions
    - *Alignment Marker:* Advanced trajectory: This hour moves learners from PCAP-level object syntax toward PCPP1-style defensive domain design: objects protect their own valid state, services communicate domain failures clearly, and caller code handles expected errors without hiding unexpected bugs.
  - **Hour 4:** Day 1, Hour 4: Composition vs Inheritance and Polymorphism
    - *Alignment Marker:* Advanced trajectory: This hour moves learners from PCAP-level object syntax toward PCPP1-style design judgment. The goal is not "use more classes." The goal is to make code easier to change by choosing the smallest useful structure: inheritance for true is-a relationships, composition for has-a relationships, and polymorphism for calling different objects through the same expected behavior.
